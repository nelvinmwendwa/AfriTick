# AfriTick — Where time meets trust

AfriTick is a watch-discovery and marketplace interface concept. This repository contains the standalone responsive front-end demo.

## Demo features
- Responsive storefront layout
- Sample watch catalogue with product photography
- Search, category filtering and price sorting
- Favourite toggle and interactive demo basket
- Product/image source links

## Important scope note
This is a front-end concept demo, not a live commerce platform. Product names and prices are illustrative. It does not connect to inventory, seller verification, user accounts, payments, shipping or order fulfilment. Do not accept real orders or payments through this demo.

## Run locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Visit http://localhost:8000.

## Assets and attribution
Watch photographs are externally hosted and linked to their source pages in the product cards. Their availability and hotlinking are controlled by the source sites. Place the AfriTick brand logo at `assets/afritick-logo.jpg`.
